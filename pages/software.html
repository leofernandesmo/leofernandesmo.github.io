SEJA — Sistema de Estágio e Jovem Aprendiz

Acessar o sistema · Saiba mais

Problema Resolvido

O campo de invenção abrange sistemas de gestão automatizada para programas de estágio e Jovem Aprendiz, com ênfase na digitalização e integração de processos administrativos. A inovação está focada em fornecer uma solução unificada para monitoramento, documentação e comunicação entre estudantes, instituições de ensino e empresas, assegurando conformidade com a legislação vigente e aumentando a eficiência operacional.

Aplicabilidade e Diferenciais

O software oferece uma série de funcionalidades inovadoras:

  • Preenchimento Automático de Documentos: Automatiza a geração de documentos necessários, reduzindo o tempo e os erros humanos.
  • Envio Automático de E-mails: Facilita o acompanhamento das etapas do estágio e do programa Jovem Aprendiz ao enviar notificações automáticas para servidores, alunos e empresas.
  • Gestão Completa de Relações: Permite o registro e a gestão detalhada de todas as relações, abrangendo termos de compromisso, aditivos, renovações, encerramentos, certificados e relatórios, tudo em conformidade com a legislação vigente.
  • Informatização Completa: Digitaliza todas as etapas do processo de estágio no âmbito do Instituto Federal de Alagoas (Ifal), promovendo eficiência e transparência.

Vantagens

arrabida — Automated Fuzz Driver Generation for Java

Replication package (OSF)

Problem

Coverage-guided fuzzing is highly effective at finding security and reliability bugs, but adoption is bottlenecked by fuzz drivers — small pieces of harness code that translate raw byte streams into valid API calls. Writing them by hand is labor- intensive, error-prone, and often impractical for the thousands of libraries with complex, interdependent APIs that OSS-Fuzz continuously tests: OSS-Fuzz reports an average coverage of around 30% across more than 1,300 projects, with driver scarcity a key contributing factor.

Approach

arrabida automates fuzz driver generation for Java libraries by combining static analysis with search-based unit test generation (via EvoSuite). It parses a target class to extract its API surface, exception behavior, and type dependencies, generates unit tests exercising that API, filters them for relevance (target reachability, public-API compliance, transformability, and expected-exception cataloging), and rewrites the survivors into a single Jazzer-compatible fuzzerTestOneInput harness — replacing hard-coded literals with fuzzer input, suppressing expected exceptions, and applying driver-level optimizations such as crash de-duplication. Unlike LLM-based driver synthesis, arrabida is fully deterministic and reproducible.

Results

In a preliminary multi-case evaluation against manually written OSS-Fuzz drivers on three real-world Java libraries (brotli-java, cbor-java, and httpcomponents-core), arrabida-generated drivers achieved higher edge coverage on all three subjects, explored a consistently larger number of distinct behavioral features, and surfaced more unique crashes overall (11 vs. 8) — including failures the manual drivers missed entirely, while still reproducing key high-impact issues.
