Teaching

This page provides information about the courses I currently teach at IFAL, including course descriptions, teaching materials, and links to the corresponding virtual learning environments (AVA).

Web Programming I

An introductory course on front-end web development, covering HTML5 markup, CSS fundamentals (selectors, the box model, and layout), and the basics of structuring and styling static web pages.

Course page →

Web Programming II

A follow-up course focused on server-side web development with Node.js and Express, covering MVC architecture, server-side templating with EJS, building CRUD applications, and an introduction to common web security vulnerabilities such as SQL injection and session management.

Course page →

Programming Languages

A course on programming paradigms and language design, with a focus on object-oriented programming in Java: classes and objects, exception handling, and the design of multi-class systems, alongside core concepts of language semantics and subprograms.
