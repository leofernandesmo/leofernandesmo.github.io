Web Programming II

The content on this page is written in Brazilian Portuguese (pt-BR), as it is intended for students enrolled in this course.

Descrição da disciplina

Programação Web

Visão Geral

Esta disciplina oferece uma formação prática e aprofundada no ecossistema de desenvolvimento web, utilizando o Node.js como base fundamental. O curso é estruturado para guiar o estudante desde uma revisão das ferramentas e conceitos básicos da web até o domínio de arquiteturas de software profissionais, testes automatizados, segurança e deploy. É um componente essencial para o estudante de Bacharelado em Sistemas de Informação que deseja compreender como projetar, construir e colocar em produção aplicações web completas, modernas e robustas.

O que você vai aprender

Ao longo da disciplina, os seguintes tópicos serão abordados:

  • Como utilizar e aproveitar ao máximo o material didático do curso.
  • Revisão da Web e suas ferramentas fundamentais.
  • Fundamentos do ambiente Node.js.
  • Desenvolvimento backend com Express, compreendendo rotas, middlewares, controllers e a estruturação profissional de um projeto.
  • Padrões de arquitetura de software, incluindo MVC (Model-View-Controller), Services e o Repository Pattern.
  • Persistência de dados e uso de bancos de dados através de ORMs como Prisma e Sequelize.
  • Técnicas de renderização no servidor utilizando o motor de templates EJS.
  • Integração do ecossistema com tecnologias modernas de frontend, especificamente Vue.js e React.
  • Implementação de sistemas de Autenticação e Autorização.
  • Garantia de qualidade por meio de testes automatizados utilizando Jest, Supertest e Playwright.
  • Práticas e conceitos essenciais de Segurança em aplicações web.
  • Estratégias de Deploy e conceitos de Infraestrutura para publicação de sistemas.

Objetivos de aprendizagem

Ao final desta disciplina, o aluno de BSI será capaz de:

  • Dominar os fundamentos do Node.js e do framework Express para a criação de servidores web.
  • Aplicar padrões arquiteturais consolidados (como MVC e Repository Pattern) para criar códigos limpos, modulares e de fácil manutenção.
  • Conectar aplicações a bancos de dados utilizando ORMs modernas (Prisma/Sequelize) e alternar entre renderização no servidor (EJS) ou integração com frameworks SPA (Vue/React).
  • Proteger aplicações web implementando fluxos de autenticação, autorização e aplicando regras rígidas de segurança.
  • Validar a estabilidade e o comportamento do software através de testes automatizados (unitários, de integração e e2e).
  • Realizar o deploy completo de uma aplicação, compreendendo os fundamentos de infraestrutura necessários.

Observação para os estudantes

Para dar suporte ao seu aprendizado prático e agilizar o desenvolvimento dos projetos e laboratórios, o material de apoio da disciplina inclui apêndices especiais com guias rápidos (cheatsheets) e sumários de comandos práticos. Utilize esses recursos como material de consulta rápida durante as aulas e no desenvolvimento das suas atividades.
