Web Programming II

The content on this page is written in Brazilian Portuguese (pt-BR), as it is intended for students enrolled in this course.

Descrição da disciplina

Curso de continuidade focado em desenvolvimento web no lado do servidor com Node.js e Express, cobrindo arquitetura MVC, templating no servidor com EJS, construção de aplicações CRUD e uma introdução a vulnerabilidades comuns de segurança web, como injeção de SQL e gerenciamento de sessões.
