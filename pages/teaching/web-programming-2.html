Web Programming II

The content on this page is written in Brazilian Portuguese (pt-BR), as it is intended for students enrolled in this course.

Descrição da disciplina

Programação Web

Visão Geral

Esta disciplina oferece uma formação prática e aprofundada no ecossistema de desenvolvimento web, utilizando o Node.js como base fundamental. O curso é estruturado para guiar o estudante desde uma revisão das ferramentas e conceitos básicos da web até o domínio de arquiteturas de software profissionais, testes automatizados, segurança e deploy. É um componente essencial para o estudante de Bacharelado em Sistemas de Informação que deseja compreender como projetar, construir e colocar em produção aplicações web completas, modernas e robustas.

O que você vai aprender

Ao longo da disciplina, os seguintes tópicos serão abordados:

  • Como utilizar e aproveitar ao máximo o material didático do curso.
  • Revisão da Web e suas ferramentas fundamentais.
  • Fundamentos do ambiente Node.js.
  • Desenvolvimento backend com Express, compreendendo rotas, middlewares, controllers e a estruturação profissional de um projeto.
  • Padrões de arquitetura de software, incluindo MVC (Model-View-Controller), Services e o Repository Pattern.
  • Persistência de dados e uso de bancos de dados através de ORMs como Prisma e Sequelize.
  • Técnicas de renderização no servidor utilizando o motor de templates EJS.
  • Integração do ecossistema com tecnologias modernas de frontend, especificamente Vue.js e React.
  • Implementação de sistemas de Autenticação e Autorização.
  • Garantia de qualidade por meio de testes automatizados utilizando Jest, Supertest e Playwright.
  • Práticas e conceitos essenciais de Segurança em aplicações web.
  • Estratégias de Deploy e conceitos de Infraestrutura para publicação de sistemas.

Objetivos de aprendizagem

Ao final desta disciplina, o aluno de BSI será capaz de:

  • Dominar os fundamentos do Node.js e do framework Express para a criação de servidores web.
  • Aplicar padrões arquiteturais consolidados (como MVC e Repository Pattern) para criar códigos limpos, modulares e de fácil manutenção.
  • Conectar aplicações a bancos de dados utilizando ORMs modernas (Prisma/Sequelize) e alternar entre renderização no servidor (EJS) ou integração com frameworks SPA (Vue/React).
  • Proteger aplicações web implementando fluxos de autenticação, autorização e aplicando regras rígidas de segurança.
  • Validar a estabilidade e o comportamento do software através de testes automatizados (unitários, de integração e e2e).
  • Realizar o deploy completo de uma aplicação, compreendendo os fundamentos de infraestrutura necessários.

Observação para os estudantes

Para dar suporte ao seu aprendizado prático e agilizar o desenvolvimento dos projetos e laboratórios, o material de apoio da disciplina inclui apêndices especiais com guias rápidos (cheatsheets) e sumários de comandos práticos. Utilize esses recursos como material de consulta rápida durante as aulas e no desenvolvimento das suas atividades.

Pré-requisitos

Esta disciplina pressupõe conhecimentos equivalentes aos de Programação Web I: HTML, CSS e JavaScript no lado do cliente. Espera-se também que o estudante tenha uma noção básica de como funciona a comunicação entre cliente e servidor usando o protocolo HTTP — embora o curso inclua, logo no início, uma revisão da Arquitetura da Web que cobre esses conceitos antes de avançar para o desenvolvimento com Node.js.

Política de colaboração

Na disciplina de Linguagem de Programação, é bem provável que você aprenda tanto (ou até mais) com seus colegas quanto nas aulas expositivas. Como acreditamos que a colaboração constrói um ambiente educacional saudável e agradável, incentivamos você a conversar com outros estudantes sobre a matéria e a formar grupos de estudo. Incentivamos especialmente a troca de experiências entre alunos que já têm mais bagagem técnica na área de Informática e aqueles que estão vindo de outros períodos ou realidades.

A menos que haja outra instrução, sinta-se à vontade para discutir as listas de exercícios com seus colegas e trocar ideias sobre como resolvê-las. No entanto, existe uma linha tênue entre colaborar e plagiar o trabalho alheio. Por isso, exigimos que você desenvolva e escreva a sua própria solução para cada lista de exercícios. Mantendo os padrões da comunidade científica e acadêmica, também exigimos que você dê os devidos créditos a quem merece. Se você utilizar uma ideia que foi desenvolvida por (ou em conjunto com) outras pessoas, por favor, faça a referência apropriada no seu trabalho. Por exemplo, se o aluno X teve uma ideia central para resolver um problema a partir do aluno Y, a solução de X deve começar com uma nota dizendo: "Trabalhei com o aluno Y neste problema" e deve indicar "A ideia principal (vinda de Y) é..." nos locais apropriados.

Ao trabalhar nas listas de exercícios, é perfeitamente aceitável consultar a literatura pública (livros, artigos, documentações oficiais, etc.) em busca de dicas, técnicas e até soluções. Contudo, você deve referenciar qualquer fonte que tenha contribuído para a sua resposta.

Listas de exercícios e gabaritos de semestres anteriores desta disciplina não são considerados parte da literatura "pública". Exigimos que você evite olhar qualquer resolução de listas de períodos passados (a menos, é claro, que o professor autorize explicitamente). É nossa política que consultar gabaritos de semestres anteriores configura plágio/cola.

O uso de Grandes Modelos de Linguagem (LLMs), como o ChatGPT ou o Gemini, pode ser um excelente aliado no dia a dia profissional, mas o seu objetivo principal agora, no IFAL, é aprender. Por isso, utilize essas ferramentas com extrema responsabilidade: o foco desta disciplina não é apenas conseguir a nota necessária para passar de ano, mas sim extrair o máximo de conhecimento possível para a sua formação e levar esse aprendizado para a sua vida profissional. Em vez de simplesmente pedir para a IA gerar o código ou a resposta pronta da lista de exercícios (a menos que a atividade peça explicitamente por isso), use a ferramenta como um tutor. Peça para o LLM explicar conceitos complexos, sugerir a lógica por trás de um problema ou apontar caminhos e documentações para que você chegue ao resultado final.
